These five static weights are mechanical instances of the approved Montserrat
variable source in `../montserrat.ttf`. The original remains unchanged. They
retain the original outlines at wght 400/500/600/700/900, names/weight metadata
are set to the corresponding instance, and the source timestamp is preserved.

The files remain under [SIL OFL 1.1](../OFL.txt), separately from software's MIT
license. See `manifest.json` for exact source/license/output hashes, generator
version and weight metadata. Regenerate with
`uv run scripts/instantiate-native-fonts.py` from the repository root. The shared
npm package contains no font binaries.
