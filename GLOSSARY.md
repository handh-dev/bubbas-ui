# Terms

- **Universal component:** one React Native primitive implementation used by
  native and React Native Web consumers.
- **Foundation tokens:** platform-neutral visual values, pinned from Brand Studio.
- **Host app:** consuming Next.js or Expo app that owns platform setup and utility
  compilation.
- **Packed consumer:** independent app installed from the actual npm tarball,
  without a workspace source alias.
- **Native bundle check:** iOS/Android Metro compilation; not native interaction
  or release qualification.
- **Visual workbench:** a public component preview for reviewing appearance and
  behavior, with implementation guidance secondary.
- **Review handback:** browser-local Keep/Change notes exported as JSON; it does
  not edit package source or approve a Studio brand change.
- **Release candidate:** locally built source awaiting final review and explicit
  publication; it is not the current public npm release.
- **Semantic theme:** a light/dark map of named color roles scoped by ThemeProvider.
- **Filmstrip:** the searchable component navigation below the live preview.
