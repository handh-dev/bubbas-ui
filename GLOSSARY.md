# Terms

- **Universal component:** one React Native primitive implementation used by
  native and React Native Web consumers.
- **Foundation tokens:** platform-neutral visual values, pinned from Brand Studio.
- **Host app:** consuming Next.js or Expo app that owns platform setup and utility
  compilation.
- **Packed consumer:** independent app installed from the actual npm tarball,
  without a workspace source alias.
- **Native bundle check:** iOS/Android Metro compilation; not native interaction
  or release qualification.
