# Foundation provenance

Brand Studio remains the owner of approved Bubba’s brand sources. This package
pins foundation values at build/release time and makes no runtime request to
Brand Studio or Core.

`src/tokens.ts` is a small universal seed: brand colors, spacing, control/panel
radii, and minimum touch targets. It does not claim parity with the full Studio
catalog or complete light/dark theme maps. The Button starts with the light
interface baseline; consumers must validate custom or dark-background treatments.

Eurostile redistribution is not cleared in the source kit. No commercial font,
Montserrat font, logo, mascot, generated artwork, or private source catalog is
included in this package. Consumers load their properly licensed local fonts
and approved artwork separately. New visual work here does not approve an asset
for the official brand library.
