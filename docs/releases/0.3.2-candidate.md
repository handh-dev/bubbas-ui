# 0.3.2 native layout and font recipe — HH-51

Installed Android review found AppearanceControl choices shrinking labels into
vertical letters. RadioGroup now reserves a readable horizontal choice basis,
wraps whole choices, bounds each to its parent and keeps the indicator unshrunk.
Existing APIs, vertical layout, disabled/form semantics and roving focus remain.

The canonical Expo SDK 57 example now uses static OFL Montserrat instances at
400/500/600/700/900 and native expo-font registration, with faithful Android XML
weights and embedded iOS family/PostScript metadata. This corrects the former
variable font's Thin default. ThemeProvider's existing host font API is unchanged.
No font binary enters npm. Web typography and foundation pins are unchanged.

Stable qualification paths: artifacts/verification/font-forwarding-latest.json,
artifacts/verification/docs/report.json, and artifacts/verification/package-latest.json.
Font prop forwarding and generated metadata are not installed paint evidence.
Fresh independent source/release review and actual native host acceptance are
required before declaring mobile typography complete. Publication is owner-led.
