# 0.3.1 host typography patch — HH-51

Native Views cannot provide text font inheritance. Before this patch, a host
could load Montserrat for app-owned text while shared PageHeader, AsyncState,
AppearanceControl, field labels and inputs still used the platform font.

Optional `ThemeProvider fontFamily` supplies the loaded host alias to all shared
text/input primitives, including control labels, feedback and native Modal
content. Nested providers inherit it. Explicit native style overrides win; code
keeps monospace. Omission preserves prior defaults. No global RN defaults or
business behavior changes. Foundation system/brand/source/digests are unchanged.

The canonical Expo example loads cleared Montserrat/OFL and passes its alias
through Gallery. The npm package still ships no font or artwork binaries.
Setup/reference/package guidance documents the same contract.

`pnpm verify:fonts` has a recorded fail-before case and renders the actual
catalog/patterns into RN primitive shims. Receipts identify prop forwarding,
not native font resolution/paint. It covers nested appearance providers, native
Modal context, explicit text/input overrides, unchanged defaults and code intent.
Installed mobile acceptance must inspect the loaded face, weights and large text.
