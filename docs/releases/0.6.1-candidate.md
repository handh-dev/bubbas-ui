## Minimal patch

Button now preserves raw caller styles on web and default native controls;
only native marketing controls compose their existing shadow. The web Pressable
adapter preserves callbacks through NativeWind class merging and resolves them
with real RNW state. Object/array styles, RTL context, refs, forms and native
rendering retain the original platform responsibilities. No CSS geometry,
colors, labels, animations, sections, icons or content change.

The existing form integration gate now also checks callback and object styles
in actual RTL SSR/browser layout, pointer/Space pressed states, focus,
disabled/loading state and reduced motion, alongside existing submit/reset,
validation, cancellation and artwork checks. This is a focused regression check,
not a new unit-test campaign.
