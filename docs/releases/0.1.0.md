Published to public npm on **2026-10-21** with the owner’s explicit approval.
Public registry metadata reports version `0.1.0`, the `latest` tag, MIT licensing,

```sh
pnpm add @bubbasfw/ui
```

This first release contains the shared React Native Button, foundation tokens,
Tailwind preset, compiled ESM/CJS, corresponding TypeScript declarations, and
source files for NativeWind utility scanning. Code is MIT licensed. Fonts and
artwork are not bundled; their distribution rights and brand trademark rights
remain separate.

## Consumer setup

Use the [consumer setup](../../README.md#install-in-a-consuming-app) alongside
installation. The baseline is React `19.2.3`, React Native `0.86.3`, React Native
Web `0.21.4`, NativeWind `4.2.7`, and Tailwind `3.4.17`. These platform packages
remain peers; React Native Web is optional for native-only consumers.

The [Expo example](../../examples/expo) includes NativeWind’s Metro and Babel
configuration. Expo apps must declare `react-native-css-interop@0.2.7` directly
and install Expo-compatible Reanimated, Worklets, and Safe Area Context versions.
The [Next.js example](../../examples/next) uses React Native Web, the Pages Router,
and explicit webpack configuration. Utility scanning must include the package’s
published source.
