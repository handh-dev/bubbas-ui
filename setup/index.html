Use the system

Start with a runnable example. Both platforms import the same components.
32 components for Web and Expo
Install @bubbasfw/ui@0.3.1 in your app, configure NativeWind, and use the same component imports on both platforms.

Run the examples

git clone https://github.com/handh-dev/bubbas-ui.git cd bubbas-ui pnpm install pnpm build pnpm dev:web # Or: pnpm dev:expo
Use Node 22.13+ and pnpm 11.15.0. The Next example runs on port 4310. Expo opens its normal development flow. The package must be rebuilt after component source changes.
Open the complete example projects

Add it to an app

React, React Native, NativeWind and Tailwind remain peer dependencies. Web also needs React Native Web and React DOM. Native-only apps can omit React Native Web.
pnpm add @bubbasfw/ui@0.3.1 nativewind@4.2.7 pnpm add -D tailwindcss@3.4.17
Pinned example baseline: React 19.2.3, RN 0.86.3, RNW 0.21.4, NativeWind 4.2.7, Tailwind 3.4.17. NativeWind 5 and Tailwind 4 need a separate migration.
The host app scans the package’s published source and loads both presets.
const path = require('node:path'); const uiRoot = path.dirname(require.resolve('@bubbasfw/ui/package.json')); module.exports = { darkMode: 'class', content: ['./App.{js,jsx,ts,tsx}', './{app,pages,src}/**/*.{js,jsx,ts,tsx}', path.join(uiRoot, 'src/**/*.{ts,tsx}')], presets: [require('nativewind/preset'), require('@bubbasfw/ui/tailwind-preset')], };
Import global CSS from the entry, with @tailwind base, @tailwind components and @tailwind utilities. Web sets important: true in its Tailwind config so utilities override RNW defaults.

Building with Xcode 27

Expo SDK 57 needs the scene-lifecycle opt-in for an iOS 27 build. Install a compatible expo-build-properties plugin and configure ios.enableSceneSupport: true before regenerating a native project. Expo 57.0.23 or newer is required; this example pins 57.0.31.
